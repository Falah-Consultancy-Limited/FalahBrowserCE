## 📖 User guide

### 1. Installation

- **macOS**: Download `FalahBrowser-1.0.1.dmg` and drag to Applications.  
- **Windows**: Download `FalahBrowser-Setup-1.0.1.exe`.  
- **Linux**: Build from source (below).

### 2. Initial setup

- Connect your **Ummah ID** on first launch to enable personalized spiritual goals.  
- Set your location under **Settings → General** for accurate prayer times.  
- Choose your **Guidance Level**:
  - **Strict**: Automatic blocking of prohibited content.  
  - **Gentle**: Visual reminders and ethical alternatives (Whisper Panel).
