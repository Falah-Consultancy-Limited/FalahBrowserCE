# Phase 02: Developer - Implementation Excellence

## Objective
To maintain a zero-technical-debt policy through strictly typed, modular, and self-documenting code.

## Core Rules
1. **Strict Typing**: Use TypeScript for all React components and logic. Python backend must use Type Hints and Pydantic.
2. **Modularity**: Every component must be single-responsibility. Hooks should be used for all stateful logic.
3. **Zero Technical Debt**: No placeholders, no `TODO`s in merged code. Every file must pass linting and formatting (Prettier/ESLint).
4. **Documentation**: Every function must have JSDoc/Docstrings. Comments should explain the *why*, not the *how*.
5. **DRY (Don't Repeat Yourself)**: Abstract common UI patterns into a local component library.

## Deliverables
- Clean, Lint-Passing Source Code
- Unit Test Coverage (>80%)
- Inline Code Documentation
